# Linux on the PS5

This wiki documents how to run Linux on the **PS5**. A jailbroken console hands control to a small payload, the Linux loader, which starts a patched Linux kernel with a full desktop.

Linux lives on a USB drive or on an M.2 SSD. The internal SSD is never written to, so the PS5 OS keeps working as before. Nothing is installed on the console itself: you run the exploit and the loader each time you want Linux, and a normal power-on starts the PS5 OS. In practice that is two devices in one: a PS5 for its own games, and a Linux PC for Steam and PC games, a desktop and emulators.

The ready-made images are a convenience, not a requirement: the PS5 kernel is stock Linux plus one patch set (see [Kernel setup](/post-install/kernel)), so any distro can be made to run, and people have brought up their own from scratch.

The downloads the video links to: the [Linux loader](https://github.com/ps5-linux/ps5-linux-loader) and [soniciso1's loader](https://github.com/soniciso1/ps5-linux-loader/releases) (see [Which loader](/getting-started/loader#which-loader)), [PS5 Bazzite Deck](https://github.com/VivaLaVent/ps5-bazzite-deck/releases) (take the release marked **Latest**), the [official images](https://github.com/ps5-linux/ps5-linux-image) and [kernel packages](https://github.com/ps5-linux/ps5-linux-patches), [balenaEtcher](https://etcher.balena.io/) and [7-Zip](https://www.7-zip.org/download.html).

Where the video and this wiki differ, follow the wiki: flash with [balenaEtcher](/installation/flash), not Rufus, and on PS5 Bazzite Deck leave `ps5_control` from ps5-linux-tools alone, because the image's own fan driver and clock governor already run the fan and clocks (see [Fan control](/troubleshooting/fan) and `ps5-perf`).

## How this wiki is organised

The wiki follows the order you need it in: **Before you install** (firmware, [hardware status](/getting-started/hardware), drives, loader and image), **Install**, **After installing** (for every image, for PS5 Bazzite Deck, and for the other distros), and **Troubleshooting**, with one page per component and one for [error messages](/troubleshooting/error-messages).

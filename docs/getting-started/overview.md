# Getting started

Linux on the PS5 is six steps: set two console settings, pick and flash an image, jailbreak, send the loader, and finish the first boot. This page is the map; each step has its own page.

:::note[Scope of this wiki]
This wiki assumes your PS5 is **already jailbroken**. It covers everything after that: booting Linux and getting the hardware working properly.
:::

:::info[Check your firmware first]
Linux only runs on exploitable system software versions. Read [Supported firmware](/getting-started/prerequisites#firmware) before you buy anything or change any settings.
:::

## What you need

**Required:**

- A PS5 on a [supported firmware](/getting-started/prerequisites#firmware)
- A USB drive of **64 GB or more**; an external SSD is much faster than a flash drive
- A USB keyboard and mouse

**Optional:**

- An M.2 SSD for a dedicated Linux install (not on the oldest firmware, see [Supported firmware](/getting-started/prerequisites#firmware))
- A USB Wi-Fi adapter, for internet access before the internal Wi-Fi driver is set up

## Steps

**Before you install**

1. [What you need](/getting-started/prerequisites): firmware, loader, drive, and the PS5 settings
2. [Choose your image](/getting-started/which-image): [PS5 Bazzite Deck](/choose/bazzite-deck) (recommended), an [official image](/choose/official-images), or [your own build](/choose/build-your-own); download and verify it

**Install**

3. [Flash the image to USB](/installation/flash)
4. Jailbreak your PS5 (not covered by this wiki), then [start Linux with the loader](/installation/booting)
5. [First boot](/installation/first-boot)

**After installing**

6. [All distros](/post-install/all-distros), then [PS5 Bazzite Deck](/post-install/bazzite) or [other images](/post-install/not-bazzite-deck)

Optional, once Linux runs: [move it to an M.2 SSD](/installation/m2-install).
